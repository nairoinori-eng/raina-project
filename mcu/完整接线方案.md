# Raina 单片机完整接线方案

这份方案按你现在的实际硬件编写：

- 主控：`Arduino Nano`
- 传感器：`FSR402 x4`
- 马达：`3V 纽扣振动马达 x2`
- 三极管：`S9012 x2`
- 按钮：`USB 手持按钮`，直接接电脑，不接 Arduino

## 1. 先看最重要的结论

旧文档里的马达驱动是按 `S8050` 写的，那是 `NPN` 低边驱动。

你现在实际用的是 `S9012`，它是 `PNP`，所以这次要改成：

- `S9012` 发射极接电源正极
- `S9012` 集电极接马达正极
- 马达负极接 `GND`
- Arduino 输出 `LOW` 时马达导通
- Arduino 输出 `HIGH` 时马达关闭

也就是说，这份接线方案和我前面给你写的固件是对应的，固件里默认就是：

```cpp
const bool MOTOR_ACTIVE_LOW = true;
```

## 3. 电源和公共地

### 3.1 基本原则

所有模块必须共享参考地，否则模拟采样和马达控制都会不稳定。

你需要先建立两条公共母线：

- `5V` 电源母线
- `GND` 地线母线

### 3.2 实际连接

1. Arduino `5V` -> 面包板红色电源轨
2. Arduino `GND` -> 面包板蓝色地线轨

如果你的面包板左右两边的电源轨不是内部连通的，还要再补两根短线：

1. 左红轨 -> 右红轨
2. 左蓝轨 -> 右蓝轨

## 4. 4 路 FSR 传感器接法

4 个 FSR 的接法完全一样，只是 Arduino 模拟口不同。

## 4.1 单个 FSR 的标准分压接法

每个 FSR 都按下面这个结构接：

```text
5V ---- FSR ----+---- A0/A1/A2/A3
                |
               10K
                |
               GND
```

这个中间节点就是 Arduino 读到的模拟电压。

## 4.2 四路分别怎么接

### S1 左胸

1. FSR 一端 -> `5V`
2. FSR 另一端 -> `A0`
3. `A0` 同时接一个 `10K` 电阻到 `GND`

### S2 右胸

1. FSR 一端 -> `5V`
2. FSR 另一端 -> `A1`
3. `A1` 同时接一个 `10K` 电阻到 `GND`

### S3 左腰

1. FSR 一端 -> `5V`
2. FSR 另一端 -> `A2`
3. `A2` 同时接一个 `10K` 电阻到 `GND`

### S4 右腰

1. FSR 一端 -> `5V`
2. FSR 另一端 -> `A3`
3. `A3` 同时接一个 `10K` 电阻到 `GND`

## 4.3 位置对应

你后面贴背心的时候，位置对应关系保持和代码一致：

- `S1`：左胸
- `S2`：右胸
- `S3`：左腰
- `S4`：右腰

代码里的计算关系是：

- 胸部差值：`S1 - S2`
- 腰部差值：`S4 - S3`

所以左右千万不要贴反，不然方向会反。

## 5. 2 路马达接法

## 5.1 先说管脚方向

这份方案按常见 `S9012 / SS9012` 的 `TO-92` 封装来写：

- 扁平面朝向你
- 引脚朝下
- 从左到右通常是：`E - B - C`

但是这里有一个必须注意的点：

不同厂家、不同批次的 `S9012` 可能存在丝印和脚位差异。正式接线前，最好对照你手里那一批器件的 datasheet 再确认一次，不要只凭经验硬插。

参考资料：

- [S9012 引脚说明（Ovaga）](https://www.ovaga.com/blog/transistor/s9012-transistor-datasheet-pinout-equivalent-and-uses)
- [SS9012 数据页索引（Fairchild）](https://www.alldatasheet.com/datasheet-pdf/pdf/54739/FAIRCHILD/SS9012.html)
- [S9012 数据页索引（Weitron）](https://www.alldatasheet.com/datasheet-pdf/pdf/154212/WEITRON/S9012.html)

## 5.2 单路马达的当前接法（无二极管版）

每个马达都按下面这个结构接：

```text
Arduino D5/D6 -- 1K -- B
                    |
                   10K
                    |
                   5V

5V -------- E  S9012  C -------- 马达正极
马达负极 ------------------------------- GND
```

说明：

- `E`：发射极，接 `5V`
- `B`：基极，通过 `1K` 电阻接 Arduino 控制脚
- `C`：集电极，接马达正极
- 马达负极直接接 `GND`
- 基极再加一个 `10K` 上拉到 `5V`，这样上电和复位时更稳，不容易乱转

### 5.2.1 你现在没有二极管，能不能先跑

可以先跑，而且你现在可以先这样接来联调和短时测试。

但我要把风险说清楚：

- 没有二极管时，马达关断瞬间的反向电动势没有额外吸收路径
- 这样会增加 `S9012` 和 Arduino 控制侧被冲击的风险
- 短时间联调通常还能做
- 长时间连续展示不如“带二极管版本”稳

所以我的建议是：

- 现在先按这份“无二极管版”接起来，先把系统跑通
- 正式展出前如果来得及，最好还是补上二极管
- 在没补二极管之前，先不要长时间让马达空转反复测很多轮

## 5.3 M1 左胸马达

1. Arduino `D5` -> `1K` 电阻 -> 第 1 个 `S9012` 的 `B`
2. 第 1 个 `S9012` 的 `E` -> `5V`
3. 第 1 个 `S9012` 的 `C` -> `M1` 马达正极
4. `M1` 马达负极 -> `GND`
5. 再补一个 `10K` 电阻：`B` -> `5V`

## 5.4 M2 右腰马达

1. Arduino `D6` -> `1K` 电阻 -> 第 2 个 `S9012` 的 `B`
2. 第 2 个 `S9012` 的 `E` -> `5V`
3. 第 2 个 `S9012` 的 `C` -> `M2` 马达正极
4. `M2` 马达负极 -> `GND`
5. 再补一个 `10K` 电阻：`B` -> `5V`

## 5.5 这和旧版 S8050 接法有什么不同

旧版 `S8050` 是低边驱动，大致是：

- 三极管发射极接 `GND`
- 集电极接马达负极
- 马达正极接 `5V`
- Arduino 输出 `HIGH` 导通

你现在这版 `S9012` 正好相反，是高边驱动：

- 三极管发射极接 `5V`
- 集电极接马达正极
- 马达负极接 `GND`
- Arduino 输出 `LOW` 导通

所以不能把旧图直接照搬。

## 6. 电机供电说明

你的马达标称是 `3V` 纽扣振动马达，而 Arduino/Nano 常用的是 `5V` 供电，这里要知道两件事：

### 6.1 和当前固件一致的简化接法

这次固件默认就是按 `5V` 总线控制来写的，但通过 `PWM` 占空比限制实际输出强度。

优点：

- 接线最简单
- 和现在给你的测试版、展出版固件直接对应

缺点：

- 马达虽然不是持续满功率，但峰值仍然是 `5V`
- 如果你买的马达很娇气，长时间运行可能会更热

### 6.2 更稳妥的做法

如果你后面发现马达过热、噪声过大、震动过猛，可以把马达供电改成单独的 `3V~3.7V` 电源，但必须满足：

1. 马达电源负极和 Arduino `GND` 共地
2. `S9012` 的发射极接马达电源正极，不再接 Arduino `5V`
3. 固件逻辑仍然保持 `LOW` 导通

如果你当前硬件已经装好了，先按现方案测试即可；正式展出前只要马达不明显发烫，一般可以先维持当前接法。

## 7. USB 手持按钮接法

这个按钮不接 Arduino。

正确接法是：

1. 手持按钮 USB 线 -> 电脑 USB 口
2. Arduino USB 线 -> 电脑 USB 口

系统结构是：

```text
手持按钮 -> 电脑(USB HID)
Arduino -> 电脑(USB Serial)
电脑 Flask -> Socket.IO -> 前端投影
```

所以按钮和 Arduino 是两条独立链路，不要把按钮信号线再并到 Nano 上。

## 8. 推荐的实际布线顺序

建议你按下面顺序接，不容易乱：

1. 先接 Arduino `5V` 和 `GND` 到母线
2. 再接 4 个 FSR 分压电路
3. 用串口监视器确认 4 路模拟值都能变化
4. 再接第 1 路马达驱动
5. 用测试固件命令 `MOTOR_LEFT:160` 单独测左胸马达
6. 再接第 2 路马达驱动
7. 用测试固件命令 `MOTOR_RIGHT:160` 单独测右腰马达
8. 最后再把全部线束整理到背心里

## 9. 上电前检查清单

上电前逐条检查：

- [ ] `5V` 和 `GND` 没有短路
- [ ] 4 个 FSR 都是“一端到 5V，另一端到模拟口，同时经 10K 下拉到 GND”
- [ ] `S1/S2/S3/S4` 没有左右贴反
- [ ] `S9012` 没有插反
- [ ] 每个 `S9012` 的基极前都有 `1K` 电阻
- [ ] 每个 `S9012` 的基极都有 `10K` 上拉到 `5V`
- [ ] 当前无二极管时，先不要做长时间连续空转测试
- [ ] 马达负极都是直接回 `GND`
- [ ] Arduino 和电脑之间 USB 已接好
- [ ] 手持按钮和电脑之间 USB 已接好

## 10. 上电后的第一轮测试

推荐你用我已经写好的 `raina_mcu_test` 固件做第一轮联调。

### 10.1 传感器测试

打开串口监视器，波特率设为 `115200`，应该能看到类似：

```text
S1:118,S2:95,S3:82,S4:147,CHEST:23,WAIST:65,RAW:39.80,BASE:11.20,ADJ:28.60,B:36
```

然后逐个按压：

- 按左胸传感器，看 `S1`
- 按右胸传感器，看 `S2`
- 按左腰传感器，看 `S3`
- 按右腰传感器，看 `S4`

如果按了某一路，变的是别的编号，说明线接错了。

### 10.2 马达测试

串口发送下面命令：

```text
MOTOR_LEFT:160
MOTOR_RIGHT:160
MOTOR_BOTH:160
MOTOR_STOP
```

如果你发现现象是“发命令就停，不发命令反而转”，那基本就是三极管极性或接法弄反了。

## 11. 最容易接错的 6 个地方

### 11.1 把旧版 S8050 图直接照搬

这是最容易犯的错。你现在是 `S9012`，接法不是一回事。

### 11.2 S9012 管脚顺序想当然

同名器件不同厂家脚位可能有差异，正式上板前一定要核对你手里那批器件。

### 11.3 忘了共地

马达供电和 Arduino 如果不共地，PWM 控制会异常。

### 11.4 FSR 少了 10K 下拉

少了这个电阻，模拟值会乱飘，几乎没法标定。

### 11.5 当前没有二极管时怎么处理

现在可以先不接，先做联调。

但要控制使用方式：

- 先做短时间功能测试
- 先确认左右马达都能正常启停
- 如果发现马达异常发热、抖动怪、突然不受控，立刻断电检查
- 正式长时间展出前，最好还是补上二极管

### 11.6 左右位置接反

代码默认：

- 左胸 = `S1`
- 右胸 = `S2`
- 左腰 = `S3`
- 右腰 = `S4`
- 左胸马达 = `M1`
- 右腰马达 = `M2`

如果你贴反了，方向判断就会反。

## 12. 最终建议

如果你现在就要开始接：

1. 先完全按这份文档把 4 个 FSR 接好
2. 马达驱动严格按 `S9012` 高边驱动接，不要参考旧 `S8050` 图
3. 基极上拉电阻建议保留，二极管你现在可以先不接
4. 先烧录 `raina_mcu_test` 联调
5. 全部确认无误后，再烧录 `raina_mcu_show` 用于正式展出
