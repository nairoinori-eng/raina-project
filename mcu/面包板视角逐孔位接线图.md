# 面包板视角逐孔位接线图

这份图按下面这个前提来写：

- 面包板类型：`标准带左右电源轨的半尺寸/全尺寸面包板`
- 中间有一条竖向凹槽
- 左半区是 `a-e`
- 右半区是 `f-j`
- 左右两侧各有一条 `红色电源轨` 和 `蓝色地线轨`
- 当前版本：`S9012` 高边驱动
- 当前版本：`无二极管`

如果你手里拿的不是这种面包板，而是 `SYB-170` 那种没有电源轨、没有中间分槽的小板，这份“逐孔位”图就不能直接照搬，但电气连接关系还是一样的。我可以再单独给你补一版 `SYB-170` 版本。

## 1. 先看坐标规则

你接线时就按这个坐标理解：

```text
左红轨   左蓝轨    a b c d e | f g h i j    右红轨   右蓝轨
```

同一行里：

- `a-e` 五个孔互通
- `f-j` 五个孔互通
- 左右中间被凹槽隔开，不互通

## 2. 整体排布建议

我建议你把面包板分成三段：

- 第 3、6、9、12 行：4 个 FSR 传感器信号节点
- 第 18-20 行：左胸马达驱动 `M1`
- 第 24-26 行：右腰马达驱动 `M2`

这样不容易乱。

## 3. 电源母线先接好

### 3.1 Arduino 到电源轨

先接这两根：

| Arduino 引脚 | 面包板孔位 |
|---|---|
| `5V` | 左红轨靠近第 `1` 行的位置 |
| `GND` | 左蓝轨靠近第 `1` 行的位置 |

### 3.2 如果你要用右边区域，也把左右电源轨桥接

再补 2 根短线：

| 起点 | 终点 |
|---|---|
| 左红轨第 `2` 行附近 | 右红轨第 `2` 行附近 |
| 左蓝轨第 `2` 行附近 | 右蓝轨第 `2` 行附近 |

## 4. Arduino 各引脚插到哪里

下面这些线先从 Arduino 拉到面包板上：

| Arduino 引脚 | 面包板孔位 | 用途 |
|---|---|---|
| `A0` | `d3` | `S1` 左胸传感器 |
| `A1` | `d6` | `S2` 右胸传感器 |
| `A2` | `d9` | `S3` 左腰传感器 |
| `A3` | `d12` | `S4` 右腰传感器 |
| `D5` | `a22` | 左胸马达控制输入 |
| `D6` | `a28` | 右腰马达控制输入 |

## 5. 四个传感器怎么插

说明一下：

- `FSR402` 本体一般不会像电阻一样直接稳稳插在面包板上
- 通常是从传感器两根引线各接一根杜邦线，再把杜邦线插进面包板

所以我这里的“孔位”指的是“传感器引出的那根信号线/电源线插到哪个孔”。

### 5.1 S1 左胸传感器

| 元件/线 | 插到哪里 |
|---|---|
| `S1` 传感器电源线 | 左红轨靠近第 `3` 行 |
| `S1` 传感器信号线 | `c3` |
| `10K` 下拉电阻一端 | `e3` |
| `10K` 下拉电阻另一端 | 左蓝轨靠近第 `3` 行 |

这一行完成后，第 `3` 行左半区 `a-e` 整排就是 `S1` 信号节点，已经同时连到：

- 传感器信号
- Arduino `A0`
- 下拉电阻到 `GND`

### 5.2 S2 右胸传感器

| 元件/线 | 插到哪里 |
|---|---|
| `S2` 传感器电源线 | 左红轨靠近第 `6` 行 |
| `S2` 传感器信号线 | `c6` |
| `10K` 下拉电阻一端 | `e6` |
| `10K` 下拉电阻另一端 | 左蓝轨靠近第 `6` 行 |

### 5.3 S3 左腰传感器

| 元件/线 | 插到哪里 |
|---|---|
| `S3` 传感器电源线 | 左红轨靠近第 `9` 行 |
| `S3` 传感器信号线 | `c9` |
| `10K` 下拉电阻一端 | `e9` |
| `10K` 下拉电阻另一端 | 左蓝轨靠近第 `9` 行 |

### 5.4 S4 右腰传感器

| 元件/线 | 插到哪里 |
|---|---|
| `S4` 传感器电源线 | 左红轨靠近第 `12` 行 |
| `S4` 传感器信号线 | `c12` |
| `10K` 下拉电阻一端 | `e12` |
| `10K` 下拉电阻另一端 | 左蓝轨靠近第 `12` 行 |

## 6. 左胸马达 M1 的逐孔位接法

## 6.1 先放三极管 Q1

把第 1 个 `S9012` 竖着插在左半区，三只脚分别占三行。

假设你已经确认你手里的 `S9012` 脚位是：

- 扁平面朝向你
- 引脚朝下
- 从左到右：`E - B - C`

那么建议这样插：

| 三极管脚位 | 面包板孔位 |
|---|---|
| `E` | `e18` |
| `B` | `e19` |
| `C` | `e20` |

也就是把三只脚稍微掰开，分别落在 `18/19/20` 三行。

## 6.2 再接 Q1 周边元件

| 元件/线 | 起点 | 终点 |
|---|---|---|
| 发射极供电跳线 | 左红轨第 `18` 行附近 | `a18` |
| 基极上拉电阻 `10K` | 左红轨第 `19` 行附近 | `a19` |
| 基极串联电阻 `1K` 一端 | `b19` | `b22` |
| Arduino 控制线 | `a22` | 已来自 `D5` |
| 马达正极引线 | `c20` | `M1` 马达正极 |
| 马达负极引线 | `M1` 马达负极 | 左蓝轨第 `20` 行附近 |

这样连接后的逻辑是：

- `e18` 那一行是发射极供电
- `e19` 那一行是基极控制
- `e20` 那一行是输出到马达正极

## 7. 右腰马达 M2 的逐孔位接法

## 7.1 先放三极管 Q2

第 2 个 `S9012` 同样方式放在左半区更靠下的位置：

| 三极管脚位 | 面包板孔位 |
|---|---|
| `E` | `e24` |
| `B` | `e25` |
| `C` | `e26` |

## 7.2 再接 Q2 周边元件

| 元件/线 | 起点 | 终点 |
|---|---|---|
| 发射极供电跳线 | 左红轨第 `24` 行附近 | `a24` |
| 基极上拉电阻 `10K` | 左红轨第 `25` 行附近 | `a25` |
| 基极串联电阻 `1K` 一端 | `b25` | `b28` |
| Arduino 控制线 | `a28` | 已来自 `D6` |
| 马达正极引线 | `c26` | `M2` 马达正极 |
| 马达负极引线 | `M2` 马达负极 | 左蓝轨第 `26` 行附近 |

## 8. 面包板顶视图简图

下面这张不是艺术图，是让你快速核对布局的。

```text
左红轨                                             左蓝轨
  |                                                   |
  |-- S1电源 ------------------------- row 03 ---------|-- S1下拉
  |-- S2电源 ------------------------- row 06 ---------|-- S2下拉
  |-- S3电源 ------------------------- row 09 ---------|-- S3下拉
  |-- S4电源 ------------------------- row 12 ---------|-- S4下拉
  |
  |-- Q1发射极供电 ------------------- row 18
  |-- Q1基极上拉 --------------------- row 19
  |-- Q2发射极供电 ------------------- row 24
  |-- Q2基极上拉 --------------------- row 25

左半区 a-e:
row03: A0  +  S1信号  +  10K到GND
row06: A1  +  S2信号  +  10K到GND
row09: A2  +  S3信号  +  10K到GND
row12: A3  +  S4信号  +  10K到GND

row18: Q1-E -> 5V
row19: Q1-B -> 10K上拉 -> 1K串联 -> D5
row20: Q1-C -> M1正极

row24: Q2-E -> 5V
row25: Q2-B -> 10K上拉 -> 1K串联 -> D6
row26: Q2-C -> M2正极

左蓝轨:
M1负极 -> GND
M2负极 -> GND
```

## 9. 你可以照着插的顺序

建议你就按这个顺序实际操作：

1. 先插 Arduino 的 `5V` 和 `GND` 到电源轨
2. 插 `A0/A1/A2/A3/D5/D6` 六根信号线
3. 完成第 `3/6/9/12` 行四个传感器节点
4. 完成第 `18/19/20` 行左胸马达驱动
5. 完成第 `24/25/26` 行右腰马达驱动
6. 再把四个传感器和两个马达本体接上

## 10. 最终核对表

接完以后你按下面核对：

- [ ] `A0` 只对应 `S1`
- [ ] `A1` 只对应 `S2`
- [ ] `A2` 只对应 `S3`
- [ ] `A3` 只对应 `S4`
- [ ] `D5` 只控制 `M1`
- [ ] `D6` 只控制 `M2`
- [ ] 两个马达负极都回 `GND`
- [ ] 两个 `S9012` 发射极都接 `5V`
- [ ] 两个 `S9012` 基极前都有 `1K`
- [ ] 两个 `S9012` 基极都有 `10K` 上拉
- [ ] 当前无二极管时，先只做短时联调，不做长时间连续空转

## 11. 第一次上电怎么测

先烧 `raina_mcu_test.ino`，然后：

1. 看串口里四路 `S1/S2/S3/S4` 有没有正常跳动
2. 逐个按压传感器，看编号是否对应
3. 发送 `MOTOR_LEFT:160`，只允许左胸马达转
4. 发送 `MOTOR_RIGHT:160`，只允许右腰马达转
5. 发送 `MOTOR_BOTH:160`，两个一起转
6. 发送 `MOTOR_STOP`，两个都停
