# v2 接口定义

## J7 TO_NANO

| Pin | 名称 | 接 Arduino Nano |
|---|---|---|
| 1 | 5V | 5V |
| 2 | GND | GND |
| 3 | A0 | A0 |
| 4 | A1 | A1 |
| 5 | A2 | A2 |
| 6 | A3 | A3 |
| 7 | D5 | D5 |
| 8 | D6 | D6 |

## J1-J4 传感器

| 接口 | Pin 1 | Pin 2 |
|---|---|---|
| J1 S1 左胸 | 5V | A0/S1_SIG |
| J2 S2 右胸 | 5V | A1/S2_SIG |
| J3 S3 左腰 | 5V | A2/S3_SIG |
| J4 S4 右腰 | 5V | A3/S4_SIG |

## J5-J6 马达

| 接口 | Pin 1 | Pin 2 |
|---|---|---|
| J5 M1 左胸 | M1_POS | GND |
| J6 M2 右腰 | M2_POS | GND |
