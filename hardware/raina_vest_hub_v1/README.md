# RAINA 背心中转控制板 v1.0

这是一块用于替代面包板的 Arduino Nano 扩展 PCB 方案。目标是把电阻、三极管、接口全部固定到一块小板上，背心内只保留 FSR 压力传感器、振动马达和延长线。

## 0. 可直接打开的 PCB 文件

本目录已经包含一套 KiCad PCB 工程：

- `raina_vest_hub_v1.kicad_pro`
- `raina_vest_hub_v1.kicad_pcb`

使用方法：

1. 安装 KiCad。
2. 打开 `raina_vest_hub_v1.kicad_pro`。
3. 进入 PCB 编辑器检查板子。
4. 核对 S9012 实物脚位、Arduino Nano 插入方向、JST 插座方向。
5. 没问题后导出 Gerber，再上传嘉立创打样。

注意：这版是为了毕业设计快速落地做的手工布线小板，不是工业量产板。下单前必须人工检查 DRC，尤其是 S9012 脚位。

## 1. 默认假设

- 主控：Arduino Nano，使用排针插到 PCB 上。
- 传感器接口：JST-XH 2P，间距 2.54mm。
- 马达接口：JST-XH 2P，间距 2.54mm。
- 电阻：直插 1/4W，间距 7.62mm。
- 三极管：S9012，TO-92 封装。
- 二极管：1N4148 / 1N4007 / 1N5819 均可，预留焊盘，正式展出建议焊上。
- PCB：2 层板，1.6mm 厚，FR-4。

## 2. 板上接口

| 接口 | 连接对象 | Arduino 引脚 | 说明 |
|---|---|---|---|
| J1 S1 | 左胸 FSR | A0 | 2P，1脚 5V，2脚信号 |
| J2 S2 | 右胸 FSR | A1 | 2P，1脚 5V，2脚信号 |
| J3 S3 | 左腰 FSR | A2 | 2P，1脚 5V，2脚信号 |
| J4 S4 | 右腰 FSR | A3 | 2P，1脚 5V，2脚信号 |
| J5 M1 | 左胸马达 | D5 | 2P，1脚马达正极，2脚 GND |
| J6 M2 | 右腰马达 | D6 | 2P，1脚马达正极，2脚 GND |

## 3. FSR 传感器电路

每一路都是同样结构：

```text
5V -> FSR -> A0/A1/A2/A3
              |
             10K
              |
             GND
```

PCB 上只放 10K 下拉电阻，FSR 本体通过 JST 线接到背心内部。

## 4. 马达驱动电路

每一路都是 S9012 高边驱动：

```text
D5/D6 -> 1K -> S9012 B
S9012 B -> 10K -> 5V
S9012 E -> 5V
S9012 C -> 马达正极
马达负极 -> GND
```

固件逻辑保持不变：Arduino 输出 LOW 时马达导通，输出 HIGH 时马达关闭。

二极管建议焊在马达两端：

```text
二极管阴极 -> 马达正极
二极管阳极 -> GND
```

## 5. 推荐 PCB 布局

参考 `raina_vest_hub_v1_top_view.svg`。

- Arduino Nano 放中间。
- 左侧放 S1-S4 四个传感器接口。
- 右侧放 M1-M2 两个马达接口。
- 每个接口旁边必须放丝印，避免背心安装时插反。
- 板子四角加 3mm 固定孔，用扎带或螺丝固定到背心外侧小盒子里。

## 6. 嘉立创EDA绘制步骤

1. 新建 2 层 PCB 工程。
2. 放置 Arduino Nano 模块插座，可以用 2 条 15P 排母代替。
3. 放置 6 个 JST-XH-2P 接口。
4. 放置 4 个 10K 下拉电阻，分别连接 A0/A1/A2/A3 到 GND。
5. 放置 2 个 S9012 TO-92、2 个 1K 电阻、2 个 10K 上拉电阻。
6. 每路马达旁预留 1 个二极管焊盘。
7. 按 `netlist.csv` 连线。
8. 铺铜：顶层和底层都铺 GND。
9. 走线建议：5V 和马达线宽 0.5mm 以上，信号线 0.25mm 以上。
10. 下单前用 DRC 检查短路和未连线。

## 7. 背心接线

背心内部每个模块做 JST 2P 插头：

```text
S1 -> J1
S2 -> J2
S3 -> J3
S4 -> J4
M1 -> J5
M2 -> J6
```

线材建议：

- FSR：28AWG 硅胶软线。
- 马达：26AWG 硅胶软线。
- 每根线 60cm 到 100cm，根据背心走线实际裁剪。

## 8. 下单前必须人工确认

- S9012 管脚顺序必须按你手里的实物确认，不同厂家可能不是同一脚位。
- JST 接口 1 脚方向要和线束一致。
- Arduino Nano 排针方向要留出 USB 插头空间。
- 如果马达供电仍用 5V，正式展出前要确认马达不明显发热。
